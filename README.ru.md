# Huld Support Bot

[English](README.md) | **Русский**

Независимый Telegram-бот технической поддержки. Пересылает обращения пользователей в закрытую Telegram-группу, создавая отдельную тему для каждого пользователя. Операторы отвечают прямо из группы, а сообщения доставляются пользователям через бота.

### Возможности

- Двусторонняя переписка через Telegram Topics
- Поддержка текста, фотографий, файлов и других вложений
- Блокировка пользователей и тихий режим
- Русская и английская локализация
- Сохранение привязок тем между перезапусками

### Стек

Python 3.12 · aiogram 3 · Valkey · Docker Compose
